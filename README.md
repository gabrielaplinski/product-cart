# Projeto carrinho de compras

Site responsivo de compras, com carrinho, botões para incluir ou remover itens, 
fechamento do pedido com revisão de itens e outras funcionalidades importantes 
para a eficácia da compra e confortáveis para enriquecer a experiência do usuário.

## Tecnologias utilizadas
- CSS3
- JavaScript
- HTML5
